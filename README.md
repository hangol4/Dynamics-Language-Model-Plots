# Dynamics-Language-Model-Plots
This repository supplements example output plots produced by my visualise_embedding.py code in the main repository [Dynamics-Language-Model](https://github.com/hangol4/Dynamics-Language-Model). The script produces 2D and 3D visualisations of chapters of 'Galactic Dynamics' by James Binney and Scott Tremaine that reflect semantic connections between them, alongside an arbitrary question. 

As the plots are interactive, the outputs are HTML files, also demonstrated in video form below:
